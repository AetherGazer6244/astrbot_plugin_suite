# 更新日志

本文件记录面向用户的变更。计划与实现细节见 [PLAN.md](./PLAN.md)，
工程约定与踩坑记录见仓库根目录的 `AGENTS.md`。

## [1.1.0] - 2026-10-19

「AI 后台实时分析、前台快速调用」：`/游戏` 的默认输出从公告列表换成 **AI 要点摘要**，
同时所有聊天输出不再携带裸网址。

### 要点摘要

- **秒回**：摘要在后台随资讯轮询自动预生成（公告有变化才生成），`/游戏` 只读缓存，
  正常路径一次 LLM 都不调；推送正文也用摘要
- **用哪个模型**：宿主默认配置档当前选中的对话模型（后台任务没有会话上下文）
- **失败兜底**：生成失败不缓存、下一轮自动重试；期间查询与推送自动退回原始列表，
  查询会附一句「AI 摘要还没备好」；刚发公告的窗口期查询会限时等待在途生成（≤20s，推送 ≤45s），
  超时不取消生成，稍后再问就有
- **摘要窗口**：默认基于最新 8 条公告（`ai_summary_max_items`，3~20），按缓存判版本，
  公告列表一变自动作废重算
- 开关：`ai_summary_enabled`（默认开；关了 `/游戏` 恒为原始列表，轮询也不再调 LLM）
- 没有可用对话模型时功能整体自动降级为原始列表，不报错

### 指令

- `/游戏`、`/游戏 <游戏名>` —— 改出 **AI 要点摘要**
- 新增 `/游戏 总结`（显式摘要，与默认视图同路）与 `/游戏 列表`（**原始列表逃生口**，
  永远不带 AI，缓存里有摘要也照给列表）
- 其余指令（卡池 / 兑换 / 版本 / 订阅 / 帮助）不变

### 输出去链接化

- 摘要、资讯列表、卡池、兑换码、B站动态、推送文案——一律不再附网址；
  日期、时间窗口、来源标注保留
- B站纯图片动态被未登录风控裁掉文字后去掉链接就什么都不剩，这种**空壳条目整条不渲染**
- 「要链接」走 AI 对话：`games_news` 工具返回给模型的内容仍含链接，模型可以贴给你

### 可靠性

- **关推送也照常轮询**（修 v1.0.0 遗留 bug）：资讯轮询还承担摘要预热与公告正文扫码入库，
  之前 `push_enabled=false` 时整条轮询不启动，与配置项说明矛盾
- 无订阅者也会扫公告正文兑换码入库（`/游戏 兑换` 的公告码源不再依赖有人订阅）
- 开机即预热摘要：不等第一个轮询周期，装好重启后马上发 `/游戏` 也能秒出要点

## [1.0.0] - 2026-10-19

首个版本。覆盖《重返未来：1999》与《明日方舟》两款游戏的官方资讯。

### 指令

- `/游戏` —— 两游戏最新资讯各 5 条
- `/游戏 <游戏名>` —— 指定游戏最新资讯
- `/游戏 <游戏名> 卡池` —— 卡池相关公告 + 从正文抽取的**活动时间段**
- `/游戏 <游戏名> 兑换` —— 兑换码（别名 `码` / `兑换码`）
- `/游戏 <游戏名> 版本` —— 版本更新公告 + **维护时间窗口**
- `/游戏 订阅 <游戏|全部|关闭>` —— 开关本会话推送（群内仅管理员，私聊人人可用）
- `/游戏 帮助` —— 使用说明

游戏名宽松识别：重返未来 / 1999 / 九九 / 重返 / RE1999 / 明日方舟 / 方舟 / ak，
全半角、空格、大小写都不敏感。二级指令不带游戏名时合并两个游戏的结果。

### AI 对话

- 三个只读工具：`games_news`（公告检索）、`games_codes`（兑换码）、`games_dynamics`（B站动态）
- 幕后提示钩子：聊到游戏话题时在 system_prompt 末尾追加固定提示，
  要求模型必须调工具取真实数据、严禁编造公告与兑换码。
  仅在消息或近几轮上下文命中关键词时注入，不命中不花 token。

### 兑换码

- 双来源自动提取：**B站官方动态正文**（主）+ **公告正文兜底扫描**（副，零额外请求）
- 自动去重、解析过期时间、剔除过期码；同一条码来自两个来源时合并来源标注
- 不提供手动登记通道

### 群订阅推送

- 新公告、新兑换码、B站新动态分别独立成条推送
- 群内仅管理员可开关订阅
- 发送成功才记账（任一会话失败则整批下轮重发，宁可重复不丢失）
- 数据源连续失败按指数退避，30 分钟封顶

### WebUI

- 插件详情页提供「B站扫码登录」标签页：扫码后 SESSDATA 自动写入配置并热生效
- 也可在配置里手动粘贴 `bilibili_sessdata`
- 登录态不会被回显到任何聊天输出、日志或 WebUI 响应
- 不登录也完全可用，只是 B站动态这条来源可能被风控拦

### 数据源实测结论

- 明日方舟 B站官方号 UID 为 **`161775300`**（官网外链 + 粉丝量双确认）
- B站 feed 请求必须带 `timezone_offset` / `platform` / `web_location`，
  否则会静默返回空列表
- B站对未登录请求会裁掉纯图片动态的文字正文，插件会明确说明原因与解法
- 方舟没有兑换码体系，`/游戏 方舟 兑换` 长期「没有兑换码QWQ」是数据源现实
